# convert_img_fmt_to_webp-GUI-

> [!IMPORTANT]
> **Archived / superseded.**
>
> This repository preserves the original GUI-only WebP conversion implementation. It is no longer actively maintained.

## Historical purpose

This project converted PNG/JPG/JPEG/GIF/SVG-oriented image inputs to WebP through a PySimpleGUI + Pillow desktop UI.

For current multi-format GUI conversion work in this GitHub collection, use `image_ext_converter_gui`, which covers WebP as well as PNG, JPEG, AVIF, HEIC, TIFF, BMP and ICO, with EXIF/transparency handling and FreeSimpleGUI support.

Repository-wide search found no implementation dependency on this legacy GUI from the owner's other repositories.

## Preserved assets

- `convert_img_fmt_to_webp(GUI).py` — original implementation
- `GUI_IMAGE_r1.webp` / `Convert to webp files_demo.webp` — historical screenshots/demo assets

## Maintenance status

No further dependency, GUI-backend, format, or CI maintenance is planned. Source and history are retained as a reference after GitHub archival.
